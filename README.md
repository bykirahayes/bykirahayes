## About

I'm Kian — an IT apprentice with a strong interest in the systems and software behind the technology we use every day.

I enjoy exploring the overlap between **IT support, development, infrastructure and automation**: from building websites and experimenting with Linux to running homelab services and creating personal assistant projects.

- 🖥️ **IT & infrastructure** — troubleshooting, networking, systems and practical support.
- 🐧 **Linux & homelab** — Linux Mint, self-hosting, servers and learning by building.
- ⚙️ **Development & automation** — web projects, scripting and tools that simplify workflows.
- 🤖 **AI experiments** — personal assistant concepts and integrations.
- 🎨 **Creative technology** — branding, web experiences and digital projects.
